## 引脚计划

最终以 CubeMX 和板子原理图为准，下面是建议起点：

| 功能 | 外设 | 引脚 | 说明 |
|---|---|---|---|
| 串口日志/通信 | USART1 | PA9 / PA10 | TX PA9，RX PA10，接 USB-TTL |
| 温湿度 + OLED | I2C1 | PB6 / PB7 | SHT30 0x44，OLED 0x3C |
| 电位器 | ADC1_IN0 | PA0 | 12 位 ADC 输入 |
| 用户 LED | GPIO | PC13 | 蓝色最小系统板常见板载 LED，低电平点亮 |
| 用户按键 | GPIO | PA1 | 可选，外接按键到 GND，内部上拉 |
| 调试 | SWD | PA13 / PA14 | SWDIO PA13，SWCLK PA14 |
| 外部 Flash | SPI1 | PA5 / PA6 / PA7 / PA4 | 选做 W25Q64，CS 用 PA4 |

接线规则：

- 所有模块共地，先接 GND，再接 3.3V，最后接信号。
- 模块供电先确认是 3.3V，不要接 5V。
- I2C 两根线不要接反：SCL 对 SCL，SDA 对 SDA。
- 杜邦线尽量短，不要频繁插拔。
- F103C8T6 只有 64 KB Flash、20 KB SRAM，FreeRTOS 的堆和任务栈要留余量。
- 1 kHz 采样不等于 1 kHz 上传；115200 波特率下建议 50-100 Hz 上报，或提高波特率。
