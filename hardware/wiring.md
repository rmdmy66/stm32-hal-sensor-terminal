# 接线表（STM32F103C8T6 + HAL）

接线前先断电。所有模块共地。F103 是 3.3 V 系统，模块优先选 3.3 V 供电。

## 1. 下载与调试：ST-Link V2

| ST-Link V2 | 接到 F103 板 | 说明 |
|---|---|---|
| SWDIO | PA13 | 数据线 |
| SWCLK | PA14 | 时钟线 |
| GND | GND | 必须共地 |
| 3.3V | 3.3V | 可给板子供电；不要再同时接别的电源 |
| RST | RST | 可选，接上更方便复位下载 |

注意：

- 只用一个电源。ST-Link 供 3.3 V 时，不要再从 USB-TTL 接 VCC。
- BOOT0 跳线保持 0，表示从主 Flash 启动。
- 下载时如果连不上，先检查 GND、SWDIO/SWCLK 是否接反、板子是否上电。

## 2. 串口日志：USB-TTL

| USB-TTL | 接到 F103 板 | 说明 |
|---|---|---|
| TXD | PA10 | USB-TTL 发，F103 收 |
| RXD | PA9 | USB-TTL 收，F103 发 |
| GND | GND | 必须共地 |
| VCC | 不接 | 板子已由 ST-Link 供电时不要接 |

串口参数：`115200-8-N-1`。

注意：

- TX 和 RX 要交叉：USB-TTL 的 TXD 接 F103 的 RX，RXD 接 F103 的 TX。
- CH340 模块如果有 3.3V/5V 选择，选 3.3V。
- 如果串口助手乱码，先查波特率和时钟，再查 TX/RX 是否接反。

## 3. 传感器与 OLED：I2C1

| 模块 | 模块引脚 | 接到 F103 板 | 说明 |
|---|---|---|---|
| SHT30 | VCC | 3.3V | 不要接 5V |
| SHT30 | GND | GND | 共地 |
| SHT30 | SCL | PB6 | I2C1_SCL |
| SHT30 | SDA | PB7 | I2C1_SDA |
| OLED | VCC | 3.3V | 与 SHT30 共用电源 |
| OLED | GND | GND | 共地 |
| OLED | SCL | PB6 | 与 SHT30 共用 SCL |
| OLED | SDA | PB7 | 与 SHT30 共用 SDA |

I2C 地址：

- SHT30：`0x44`
- OLED：`0x3C`

如果模块自带上拉电阻，不要再外加。如果没有，需要在 SCL/SDA 到 3.3V 之间各加一个 4.7 kΩ 电阻。优先买带电平转换和上拉的模块。

## 4. 电位器：ADC1

| 电位器 | 接到 F103 板 | 说明 |
|---|---|---|
| VCC | 3.3V | 模块版通常三个脚 |
| GND | GND | 共地 |
| OUT | PA0 | ADC1_IN0 |

注意：ADC 输入电压不能超过 3.3 V。

## 5. 按键：可选

最小系统板通常没有独立用户按键。先用一根杜邦线把 `PA1` 短接到 `GND` 模拟按键：

- PA1 配置为输入上拉
- 松开：PA1 为高
- 按下/短接：PA1 为低

不要用 PA0 做按键，PA0 留给 ADC 电位器。

## 6. 逻辑分析仪

| 分析仪 | 接到 |
|---|---|
| GND | 板子 GND |
| CH0 | PB6（I2C SCL） |
| CH1 | PB7（I2C SDA） |
| CH2 | PA9（USART1 TX） |

先用 1 MHz 采样，能看清 I2C 波形后再调整采样率。

## 7. 上电检查顺序

1. 断电，接 GND。
2. 接 3.3 V。
3. 接信号线。
4. 上电，用万用表量模块 VCC 是否为 3.3 V。
5. 先只跑 LED 和串口，确认下载、日志正常。
6. 再接 I2C 传感器和 OLED。

## 8. F103C8T6 资源提醒

- Flash：64 KB；SRAM：20 KB。
- 1 kHz 采样可以，但 115200 波特率下不要每毫秒上传一帧。
- 建议 1 kHz 采样、50-100 Hz 上报，或提高波特率。
- FreeRTOS 堆建议先从 6-8 KB 开始，任务栈按实际高水位调整。
